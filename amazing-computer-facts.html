30 Amazing Computer Questions & Answers

Curious Questions, Clear Answers

Each answer starts with the core idea, then adds the detail that makes it interesting. Select any question to read the explanation.

1. How does a USB drive remember my files for years with no battery?
Hardware & Memory

A USB drive uses NAND flash memory, a type of non-volatile storage. Its memory cells store information by representing different electrical charge levels. They do not need continuous power to keep the data.

Stored charge can gradually leak, and memory cells can wear out. A USB drive can preserve data for years under suitable conditions, but it is not permanent storage. Keep another backup of important files.

2. Why do computers use only 0 and 1?
Hardware & Memory

Digital circuits can reliably distinguish between two states, such as a low voltage and a high voltage. These states are represented as 0 and 1, called bits.

Long patterns of bits can represent numbers, text, images, sound and instructions. Real computers contain many more electrical details, but binary makes digital logic practical and reliable.

3. How does Wi-Fi send data through the air?
Internet & Web

Wi-Fi sends data using radio waves. Your device converts digital data into a radio signal, and the router receives and decodes it. The router then forwards the data to your local network or the internet.

Walls, distance, interference and competing networks can weaken or disrupt the signal, which is why Wi-Fi speed varies from place to place.

4. Why doesn't deleting a file always erase it permanently?
Software & Data

Deleting a file often removes its directory entry or marks its storage space as available. The underlying data may remain until that space is reused or the storage device securely processes it.

That is one reason recovery tools can sometimes restore deleted files. On SSDs, TRIM and the drive's internal processes make the details more complex. Use appropriate secure-erasure tools when sensitive data must be removed.

5. How can a search engine find web pages so quickly?
Internet & Web

Search engines generally do not search the entire live web from scratch for every query. They discover pages with crawlers, analyze them, and store information in large, distributed indexes.

When you search, systems retrieve and rank likely relevant results from that index. Results can still be missing, delayed or outdated, and ranking depends on many signals.

6. What does a CPU actually do?
Hardware & Memory

The central processing unit (CPU) executes program instructions. It performs calculations, makes comparisons, moves data and coordinates work with memory and other components.

The CPU is not the whole computer: storage keeps files, RAM holds working data, and other processors such as GPUs handle particular workloads efficiently.

7. Why does RAM usually forget data when the computer turns off?
Hardware & Memory

Most main memory is volatile. DRAM stores bits using tiny electrical charges that must be refreshed repeatedly. When power is removed, the stored state quickly disappears.

That makes RAM fast and useful for active programs, while SSDs and hard drives are designed to retain data without continuous power.

8. Why is an SSD usually faster than a hard drive?
Hardware & Memory

A traditional hard disk drive has spinning platters and a moving read/write head. Finding data involves mechanical movement. An SSD uses flash memory and has no moving parts, so it can access many pieces of data much more quickly.

Actual speed depends on the drive type, interface, workload and computer. Both SSDs and HDDs can fail, so backups still matter.

9. What is a cache, and why does it make things faster?
Software & Data

A cache keeps copies of data that may be needed again soon. If the data is still valid, a system can reuse the cached copy instead of fetching or calculating it again.

Browsers cache images and files, CPUs cache recently used instructions and data, and applications cache results. A stale or corrupted cache can sometimes cause problems, which is why clearing it may help in troubleshooting.

10. What does HTTPS protect when I visit a website?
Security & Privacy

HTTPS uses TLS to encrypt data sent between your browser and the website and helps protect against undetected tampering. Certificates also help the browser verify the server's identity for the domain.

HTTPS does not automatically mean a website is honest, safe to buy from, or free of malware. It protects the connection, not every action or claim made by the site.

11. What is an IP address, and why does a device need one?
Internet & Web

An IP address is a network address used to deliver internet-protocol traffic to the right destination. Devices use addresses to communicate across local networks and the wider internet.

Addresses may be private or public, static or dynamically assigned. An IP address does not always identify one person or one device permanently.

12. How does a browser know where a domain name points?
Internet & Web

The Domain Name System (DNS) helps translate names such as example.com into records, often including IP addresses, that computers can use to connect to services.

DNS answers can be cached for a period of time. This speeds up repeat lookups, but it also means DNS changes may not appear everywhere immediately.

13. Why are there two slashes after http: in a URL?
Internet & Web

In a URL such as https://example.com, the double slash introduces the authority portion, which commonly contains the host name and may include a port or user information.

The convention comes from the URL syntax used by web technologies. Not every kind of URI uses the same structure, so the double slash is not required in every possible URL.

Related reading: URL vs URI vs URN and HTTP vs HTTPS.

14. Does Incognito mode make me completely anonymous?
Security & Privacy

No. Private or Incognito mode mainly limits what the browser saves locally after the private session, such as browsing history and cookies for that session.

Websites, employers or schools managing the network, and internet service providers may still be able to observe some activity. Downloads and bookmarks may remain on the device, too.

15. Why do websites use cookies?
Software & Data

Cookies are small pieces of data that a website asks a browser to store and send back in later requests. They can maintain a login session, remember preferences, support shopping carts or help measure site usage.

Cookies are not programs that run by themselves, but they can be used as part of tracking systems. Browser settings let you manage or delete many cookies.

16. What does a firewall actually do?
Security & Privacy

A firewall applies rules to network traffic and allows or blocks connections based on factors such as addresses, ports, protocols or application policies.

It can reduce unwanted network access, but it is not a complete security solution. Updates, secure passwords, backups and safe browsing habits are still important.

17. Does a VPN hide everything I do online?
Security & Privacy

A VPN creates an encrypted tunnel between your device and a VPN server. It can protect traffic from some observers on the local network and makes websites see the VPN server's public IP address rather than your original one.

A VPN does not make you fully anonymous. The VPN provider may see connection information, websites can still track accounts or browser activity, and phishing or malware risks remain.

18. How can Bluetooth connect devices without a cable?
Internet & Web

Bluetooth uses short-range radio communication to exchange data between nearby devices. Devices discover each other, establish a connection and use agreed profiles or services to handle tasks such as audio, keyboards or file transfer.

Walls, interference, distance, battery-saving settings and device compatibility can affect connection quality.

19. What does an operating system do?
Software & Data

An operating system, such as Windows or Linux, manages hardware resources and provides common services to applications. It handles processes, memory, files, devices, permissions and user interaction.

Applications rely on the operating system instead of each having to control every hardware component directly.

20. Why do computers have a GPU as well as a CPU?
Hardware & Memory

A CPU is designed for flexible, low-latency work across many kinds of instructions. A GPU contains many processing units that can perform large numbers of similar operations in parallel.

This is useful for graphics and many scientific or AI workloads. Not every task benefits from a GPU, and modern CPUs can also handle graphics or parallel work in some systems.

21. What does “the cloud” really mean?
Software & Data

Cloud computing means using computing resources—such as storage, databases, applications or processing power—provided over a network by a service provider.

The files and processing still run on physical computers in data centres. Cloud services can make access and scaling easier, but availability, privacy, costs and backups still need attention.

22. How does AI learn from data?
AI & Computing

Many AI systems use machine learning: during training, an algorithm adjusts model parameters based on examples and a defined objective. The trained model can then use learned statistical patterns to make predictions or generate outputs.

AI does not learn exactly as humans do, and it can produce incorrect or misleading answers. Results should be checked, especially when accuracy matters.

23. Why should websites store password hashes instead of plain passwords?
Security & Privacy

A website should not keep users' passwords in readable plain text. It should use a password-hashing method designed for passwords, such as Argon2id, scrypt or bcrypt, with a unique salt.

When a user signs in, the system checks the submitted password against the stored hash. Hashing is not the same as encryption, and weak passwords can still be guessed—so secure storage and multi-factor authentication both matter.

24. Why is two-factor authentication safer than a password alone?
Security & Privacy

Two-factor authentication requires another proof of identity in addition to a password—for example, a security key, authenticator code or device approval. A stolen password alone may then be insufficient to access the account.

Phishing-resistant passkeys or security keys are generally stronger against fake sign-in pages than SMS codes. Keep recovery methods secure, too.

25. How can Ctrl+Z undo something I just did?
Software & Data

Many applications keep an undo history describing recent changes, such as text edits or drawing actions. Ctrl+Z asks the application to reverse the most recent supported action.

Undo history is usually limited and may be cleared when a file or application closes. Not every action can be undone, so save important work regularly.

26. How does a computer take a screenshot?
Software & Data

A screenshot feature asks the operating system or application to capture the current screen image as pixel data, then save it or copy it to the clipboard.

Protected video, secure screens, multiple displays and application permissions can affect what gets captured. A screenshot may also contain private information, so check it before sharing.

27. How can a ZIP file make files smaller without losing them?
Software & Data

ZIP archives commonly use lossless compression methods that encode repeated or predictable patterns more efficiently. When extracted correctly, the original file contents can be reconstructed exactly.

Already-compressed formats such as JPEG images or MP4 videos may shrink very little. Lossy compression is different because it discards some information to reduce size.

28. Why isn't keeping files on one external drive enough for a backup?
Software & Data

A single external drive can fail, be lost, damaged, stolen or infected while connected to a compromised computer. A backup is useful only if a working copy remains available when the original is lost.

Keep multiple copies on separate devices or locations, include an offline or protected copy when possible, and test that files can actually be restored.

29. How can a computer run programs if it doesn't understand human language?
AI & Computing

Programs are translated or interpreted into operations that the processor and its supporting software can execute. At the hardware level, digital circuits respond to encoded instructions and data—not to human meaning in the way people understand it.

Programming languages, compilers, interpreters and operating systems provide layers that make those operations easier for humans to create and manage.

30. How can a QR code store information in a small square?
Internet & Web

A QR code represents data using a pattern of dark and light modules. Its finder patterns help a scanner locate and orient the code, while encoding and error-correction data help recover the message.

A QR code may contain a website address or other text. Scanning one does not guarantee the destination is safe, so check the link before opening it.
