Router destination IP ke basis par packets ko next network path ki taraf kaise forward karta hai.

Simple flow: User action → Device hardware → Controller/processing → Data transfer or output

Router kya karta hai?

Router different IP networks ke beech packets forward karta hai. Ye destination address dekh kar next-hop/interface choose karta hai.

Routing table

Router ke paas routes ka set hota hai. Longest-prefix matching jaise rules ke through destination ke liye appropriate route select kiya jata hai.

Packet forwarding

Incoming packet ke destination IP ko inspect karke router next-hop decision leta hai aur packet ko selected interface par bhejta hai.

NAT

Home routers commonly private network addresses ko internet-facing public address ke saath translate karne ke liye NAT use karte hain.

Router aur switch mein difference

Switch primarily local network mein frames forward karta hai, jabki router IP networks ke beech packet forwarding karta hai.

FAQ

Is topic ko samajhna kyun useful hai?

Is device ka basic working samajhne se common performance, connectivity aur storage behavior ko samajhna easier hota hai.

Kya actual performance specifications par depend karti hai?

Haan. Hardware generation, interface, controller, workload aur connected system ke capabilities ke according real-world performance change ho sakti hai.
