🧠 What is Git?

Git is a version control system — it tracks your code changes, so you can:

  • Save progress safely (like checkpoints)
  • Work in teams without overwriting code
  • Go back to any previous version

⚙️ Step 1: Install Git

👉 Download from git-scm.com

  • Keep default settings
  • After install, run:
git --version

✅ If you see a version number, you’re ready!

🧩 Step 2: Set Up Git (only once)

git config --global user.name "Your Name"
git config --global user.email "your@email.com"

📁 Step 3: Create or Open a Project

cd path/to/your/project
git init

This creates a hidden .git folder — your project is now version-controlled!

🧾 Step 4: Check Status

git status

Shows which files are new, changed, or staged.

💾 Step 5: Stage and Commit Changes

git add filename        # add single file
git add .               # add all files
git commit -m "Your message here"

🌍 Step 6: Connect to GitHub

  1. Create a new repo on GitHub
  2. Copy the repo URL (HTTPS)
  3. Link it:
git remote add origin https://github.com/username/repo-name.git
git push -u origin main

🔄 Step 7: Everyday Git Workflow

git status              # check what changed
git add .               # stage
git commit -m "explain your change"
git push                # upload to GitHub
git pull                # get latest updates

🌱 (Optional) Branching

git checkout -b new-feature
git checkout main
git merge new-feature

💡 Bonus: Using Git in VS Code

  • Open your project in VS Code
  • Click Source Control icon (left sidebar)
  • You’ll see all changed files
  • Click + to stage, type a commit message, click ✅ to commit
  • Click “Sync Changes” to push/pull from GitHub
