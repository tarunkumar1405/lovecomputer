LAN Wire & RJ45 Connector Kaise Banaye? (T568B)

CAT5e/CAT6 LAN cable mein RJ45 connector lagane ka simple step-by-step guide — color code, crimping aur cable testing ke saath.

Yaad rakhne ka order: White-Orange → Orange → White-Green → Blue → White-Blue → Green → White-Brown → Brown.

RJ45 Connector Lagane Ka Step-by-Step Tarika

1. Outer Jacket Strip Karein
🔵✂️

Cable ke end se lagbhag 2–3 cm outer jacket carefully remove karein. Andar ke conductors ko cut na karein.

2. 8 Wires Separate Karein
🧵🧵🧵

Twisted pairs ko gently open karke 8 individual wires ko seedha karein.

3. T568B Order Set Karein
🟧🟧🟩🟦🟦🟩🟫🟫

Pin 1 se 8 tak T568B color sequence mein wires arrange karein.

4. Wires Same Length Mein Cut Karein
✂️

Sabhi wire ends ko ek straight line mein cut karein.

5. RJ45 Mein Insert Karein
🔌

Color order dobara check karke wires ko RJ45 plug mein poori tarah insert karein. Wires contacts tak pahunchni chahiye.

6. Crimping Tool Se Press Karein
🛠️

RJ45 plug ko crimping tool mein rakhkar firmly press karein, phir connector ko visually inspect karein.

Cable Tester Se Check Kaise Karein?

Crimping ke baad cable tester se connection verify karein. 1 se 8 tak sequence correct aana chahiye.

Frequently Asked Questions

RJ45 connector mein kitne pins hote hain?

Ethernet RJ45 connector mein 8 contacts/pin positions hote hain.

T568A aur T568B mein kya difference hai?

Dono wiring standards hain. Orange aur green pairs ki positions alag hoti hain.

Kya CAT5e aur CAT6 se LAN cable bana sakte hain?

Haan, compatible cable aur connectors use karke bana sakte hain.

Kya ghar par LAN cable bana sakte hain?

Haan. Cable, RJ45 connectors, crimping tool aur tester se easily bana sakte hain.

Useful Tips

  • Connector insert karne se pehle color order do baar check karein.
  • Wires ko unnecessarily zyada untwist na karein.
  • Crimping ke baad cable tester se test karein.
  • Achhi quality ke cable aur RJ45 connectors use karein.
Safety: Crimping tool aur cable cutter ko carefully use karein aur bachchon se door rakhein.

Conclusion

T568B color code follow karke RJ45 connector lagana simple hai. Sabse important hai correct color sequence, proper insertion aur cable testing.
