How to Share a Printer on a Network in Windows

Printer Problems · September 22, 2026

If a printer is connected to one Windows computer and you want other computers on the same local network to use it, you can share the printer through Windows.

ADVERTISEMENT

Before You Start

  • Make sure the printer works normally on the main computer.
  • Both computers should be connected to the same local network.
  • The main computer should remain switched on when another computer wants to print.

Step 1: Turn On Network Discovery and Printer Sharing

  1. Open Settings or Control Panel.
  2. Open Network and Sharing Center and choose Change advanced sharing settings.
  3. Turn on Network discovery.
  4. Turn on File and printer sharing.
  5. Save the changes.

Step 2: Share the Printer

  1. Open Settings → Bluetooth & devices → Printers & scanners.
  2. Select the printer you want to share.
  3. Open Printer properties.
  4. Go to the Sharing tab.
  5. Select Share this printer.
  6. Enter a simple Share name, then click Apply and OK.
Tip: Use a short, easy-to-remember printer share name without unnecessary spaces.

Step 3: Find the Computer Name

On the computer where the printer is connected:

  1. Open Settings → System → About.
  2. Find the Device name.
  3. Note this name because the other computer will use it to access the shared printer.

Step 4: Connect from Another Computer

On the second Windows computer:

  1. Press Windows + R.
  2. Type the following format:
\\ComputerName\PrinterShareName

For example:

\\OFFICE-PC\HP-LaserJet
  1. Press Enter.
  2. Windows should display the shared printer.
  3. Double-click the printer to connect it.
  4. Allow Windows to install the required printer driver if prompted.

If the Shared Printer Is Not Found

  • Check that both computers are connected to the same network.
  • Make sure Network discovery is enabled.
  • Make sure File and printer sharing is enabled.
  • Check that the printer is actually shared.
  • Restart both computers and try again.
  • Check Windows Firewall settings if network sharing is blocked.

Important

A printer connected by USB to one computer usually depends on that computer being powered on and connected to the network. If you want the printer to be available independently, a network-enabled or Wi-Fi printer may be more convenient.
