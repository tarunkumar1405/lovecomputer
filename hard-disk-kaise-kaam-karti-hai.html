Hard Disk (HDD) Kaise Kaam Karti Hai?

HDD ke platter, spindle, actuator arm aur read/write heads data ko kaise store aur read karte hain.

HDD ke platter, spindle, actuator arm aur read/write heads data ko kaise store aur read karte hain.

Simple flow: User action → Device hardware → Controller/processing → Data transfer or output

HDD ke main parts

HDD mein magnetic platters, spindle motor, read/write heads, actuator arm, controller electronics aur enclosure hote hain.

Data magnetic surface par kaise store hota hai?

Platters ki magnetic surface par microscopic regions ki magnetization ko controlled patterns mein represent kiya jata hai. Head in patterns ko sense karta hai aur writing ke waqt magnetic state change karta hai.

Read aur write process

Spindle platter ko rotate karta hai. Actuator arm head ko required track ke paas position karta hai. Controller desired sectors ke read/write operations coordinate karta hai.

HDD slow kyun hoti hai?

Mechanical movement—head positioning aur platter rotation—access time add karta hai. SSD mein aise moving parts nahi hote.

HDD ki capacity ka fayda

HDDs large-capacity bulk storage ke liye commonly useful hoti hain, especially jab cost per stored GB important ho.

FAQ

Is topic ko samajhna kyun useful hai?

Is device ka basic working samajhne se common performance, connectivity aur storage behavior ko samajhna easier hota hai.

Kya actual performance specifications par depend karti hai?

Haan. Hardware generation, interface, controller, workload aur connected system ke capabilities ke according real-world performance change ho sakti hai.
